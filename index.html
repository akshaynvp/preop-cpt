Author

Akshay Pulavarty, MD, MPH
Dermatology Resident, NYU Langone Health

This tool was built to assist dermatology residents and surgical team members with pre-operative CPT code estimation for common dermatologic surgical procedures.

Code outputs are estimates only and should be verified against current CPT guidelines and institutional billing compliance policies before submission. The tool does not constitute legal, financial, or medical advice.

For questions or feedback, contact: akshaynvp@gmail.com
